# Автономная Android-демонстрация

APK: `artifacts/ModusTrade-demo.apk`. Android 8.0+ с обновлённым Android System WebView (Chrome 100+ рекомендуется). Это устанавливаемая демонстрационная сборка, подписанная отладочным ключом.

Приложение упаковывает существующие React-компоненты сайта и локальные шрифты в Android WebView. Сервер, PostgreSQL, Docker и интернет для работы не нужны. В манифесте нет разрешения INTERNET. Веб-адрес https://app.local/ обслуживается из ресурсов APK, он не является внешним сервером.

## Демонстрация

Войти: `admin` / `admin` или `user` / `user`. Для других ролей доступны логины из `scripts/catalog.ts`, например `employee.procurement`, `manager.procurement`, `responsible.catalog`; начальный пароль `demo12345678`. Это публичные демонстрационные аккаунты, реальные данные в них вводить не следует.

В комплекте 20 вымышленных обращений. Можно создать обращение сотрудником, выйти, войти руководителем, добавить ответ и изменить статус, затем вернуться автором для оценки результата. Также доступны фильтры, вложения, аналитика, языки, темы, профиль и локальное администрирование. Файлы выбираются стандартным диалогом Android.

База — IndexedDB внутри хранилища приложения. Текущая сессия и изменения сохраняются после закрытия и повторного открытия. Вложения сохраняются в той же базе. При очистке данных или удалении APK база удалится; следующий запуск создаст исходное демо заново. На разных телефонах независимые базы. Пароли сохраняются как PBKDF2-хеши, старые записи автоматически переносятся; серверной границы доверия в офлайн-демо нет: эта версия предназначена для показа, не для эксплуатации с реальными персональными данными.

Напоминания появляются внутри открытого приложения. Фоновых push-уведомлений и синхронизации с сайтом нет. Telegram отключён: ему нужен серверный обработчик и интернет. IndexedDB заменяет серверный слой только в мобильной сборке; веб-приложение продолжает использовать PostgreSQL.

## Сборка

Нужны Node.js 22+, JDK 17/21 и Android SDK 35. Указать SDK через `ANDROID_HOME` или `mobile/android/local.properties` (`sdk.dir=...`).

```sh
npm ci
npm run mobile:build
cd mobile/android
./gradlew assembleDebug
# Windows: gradlew.bat assembleDebug
```

Результат: `mobile/android/app/build/outputs/apk/debug/app-debug.apk`. В Android Studio можно открыть `mobile/android` после `npm run mobile:build`.

## Проверки

Пройдены TypeScript, сборка статических ресурсов и Android APK. В Chromium с размером экрана телефона проверены вход, создание обращения, комментарий и сохранение после перезагрузки. APK проверяется apksigner. Запуск на физическом Android-устройстве не проверен.

## Исправления безопасности

Исходный код включает ограничения WebView, хеширование паролей, защиту полей профиля и анонимных данных. Подробности: [отчёт](../docs/security-review.md). APK `artifacts/ModusTrade-demo.apk` выпущен до этих исправлений и не обновлён: требуется новая сборка через Android SDK 35.
