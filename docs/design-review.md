# Обновление интерфейса кабинета

Проверены обзор, навигация, уведомления и создание обращения в светлой и тёмной темах, а также мобильная версия и три языка интерфейса.

| Наблюдение                                                               | Изменение                                                                                                                    |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| В сетке обзора короткая панель обращений растягивалась до высоты истории | Выравнивание панелей по верхнему краю; нижняя граница следует за последней записью                                           |
| Числа статистики не давали представления о динамике                      | График поступивших и завершённых обращений за 7/30 дней и диаграмма текущих статусов с переходом к фильтру                   |
| Синяя боковая панель резко выделялась на фоне кабинета                   | Графитовый градиент, красный активный пункт, единые состояния наведения и фокуса                                             |
| Узкое окно уведомлений затрудняло чтение и поиск новых событий           | Более широкая панель, фильтр непрочитанных, счётчик, иконки событий, явный переход, закреплённая шапка и отдельная прокрутка |
| Анонимная отправка была отдельным большим блоком внутри формы            | Компактный переключатель слева от действий, без пояснения; на узком экране строка переносится                                |
| Инструкция требовала читать список и запоминать последовательность       | Пять шагов на настоящих элементах интерфейса с подсветкой, описанием, переходами, пропуском и повторным запуском             |
| Периодическое обновление кабинета повторно запускало эффект фокуса формы | Стабильные обработчики открытия и закрытия; сохранение фокуса проверяется при обновлении уведомлений                         |
| Подписи SVG уменьшались вместе с графиком на телефоне                    | Система координат графика адаптируется к ширине контейнера через ResizeObserver                                              |
| Страница могла прокручиваться под открытой формой                        | Прокрутка фона блокируется до закрытия формы                                                                                 |

Графики используют доступные текущему пользователю обращения, без вымышленных значений. Дневные интервалы считаются в UTC; завершения относятся к дате завершения, включая обращения, созданные раньше выбранного периода. Точные значения доступны в раскрываемой таблице. Нулевые данные показаны явно.

Экскурсия не создаёт обращений: отправка блокируется на всём протяжении обучения, а нажатие выделенной кнопки на последнем шаге завершает экскурсию и оставляет форму открытой. Клавиатурный фокус ограничен подсвеченным элементом и подсказкой; Escape пропускает обучение. Постоянный отказ от повторного показа сохраняется в профиле.

Анимации открытия панелей, смены шага, подсветки и наведения учитывают `prefers-reduced-motion`. Центр уведомлений закрывается кнопкой, Escape и нажатием вне панели с возвратом фокуса к колокольчику.

Автоматические проверки находятся в `tests/browser/design.spec.ts`; расчёт дневных значений проверяется в `tests/domain.test.ts`. Проверяются реальные данные API, граница панели, фильтры и прочтение уведомлений, отсутствие создания обращения при обучении, сохранение отказа от тура, фокус после фонового обновления, мобильная ширина, обе темы и все языки.
