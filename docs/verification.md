## Ограничения проверки среды

Полная сборка Docker Compose была запущена, но остановилась на загрузке инструмента Prisma: прокси этой Cloud-среды возвращает `403 Domain forbidden` для `binaries.prisma.sh`. Запрошено разрешение домена. Проверки SQL-схемы проведены применением SQL-миграции к отдельной PostgreSQL, приложение использует JS-адаптер Prisma. Для локальной production-сборки генератор был запущен без загрузки неиспользуемого нативного движка; runtime не использует заглушек и обращается к PostgreSQL через штатный PrismaPg.

Дополнительно собран отдельный проверочный runtime-образ из уже скомпилированного standalone-приложения. Он работает на штатном Node.js 22, без заглушек, с PrismaPg и отдельным volume для файлов. Созданы обращение, комментарий и приватный файл; после перезапуска обоих контейнеров данные прочитаны успешно. Это проверяет runtime и сохранность данных, но не заменяет полную установку по основному Dockerfile.

Стандартный Dockerfile и `prisma migrate deploy` требуют загрузки официального инструмента при первой сборке на ПК. GitHub Actions содержит отдельную проверку чистой Compose-установки и перезапуска. Успех этого задания нельзя считать подтверждённым до завершения CI. Windows PowerShell и macOS здесь не исполнялись; это остаётся частью проверки на целевых ПК.

Скачивание браузера Playwright также ограничено политикой среды. Браузерные сценарии успешно выполнены установленным системным Chromium через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`.

## Известные границы MVP

- Нет внешних интеграций, email, SSO, анонимных обращений и внешнего AI.
- Анализ тем — повторяющиеся слова без морфологического анализа.
- Категории и стандартные названия подразделений переведены; произвольные имена и пользовательский контент не переводятся автоматически.
- Уведомления обновляются опросом каждые 30 секунд; показываются последние 100, массовое прочтение действует на все.
- Файлы проверяются по типу, размеру и сигнатуре; антивирус не включён. При аварийном завершении процесса может остаться недоступный через API файл без метаданных.
- При неудаче загрузки вложения после создания текста карточка уже существует: ошибка показывается, загрузку можно повторить в ней.
- Номера возрастают, но PostgreSQL может оставлять пропуски при откате.
- Демоимпорт не перезаписывает существующие записи и не меняет пароли. Новые демозаписи могут создаваться, если прежние вручную удалены из БД.
